Windows notes

- This project will auto-detect a bundled ffmpeg at `./ffmpeg/bin/ffmpeg.exe` if found, otherwise it uses `ffmpeg` from PATH.
- If LaTeX (MiKTeX) isn’t healthy, the system falls back to Pango `Text`. To enable MathTex, open MiKTeX Console and update packages.
- Use a Python 3.10 venv and `pip install -r requirements.txt`.
